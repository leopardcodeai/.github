# LeopardCode.AI

AI systems for organisations that work with their own documents. Built in
Germany, run where the customer decides, with the data route written down
before the first request goes out.

**Dr.-Ing. Alexander Brunker** · AI Solution Architect · Hückelhoven, Germany

## What we build

- **AMANA**, a knowledge system for files that stay in the house. Retrieval
  over your own documents, a source named for every answer, pseudonymisation
  before every model call, and the choice of where the model runs.
  [amana.leopardcode.ai](https://amana.leopardcode.ai)
- **Consulting and engineering** for RAG pipelines, on-premises models and
  GDPR-native architectures. [leopardcode.ai](https://leopardcode.ai)
- **Training**: a one day workshop on the EU AI Act, with your own documents
  and a file note at the end.
